## 教训（geren.md 清理时引入的回归，已修复）

把 `.desktop-only { display: none !important }` 的 !important 删掉后，裸类选择器 (0,1,0) 被主题 `.md-typeset .grid { display:grid }` (0,2,0) 压制，移动端桌面区块重新显示。修复：改为 `.md-typeset .grid.desktop-only { display: none }` (0,3,0)。教训：**覆盖主题 display/grid 类规则时，删 !important 必须同步提高选择器特异性，不能只删不提**。

## geren.md 移除 Font Awesome CDN（已修）

- Zensical 内置 5 套图标集（FontAwesome/Octicons/Material/Lucide/Simple Icons），图标文件在 `.venv/.../zensical/templates/.icons/<集>/<样式>/<名>.svg`，shortcode = 路径 `/` 换 `-`
- 页面日历图标在**原始 HTML 块**内（无 markdown="1"），`:fontawesome-regular-calendar:` shortcode 不会被解析 → 直接内联主题包里 `fontawesome/regular/calendar.svg` 的 SVG，包 `<span class="twemoji">` 获得主题的尺寸/对齐样式
- `<i class="fa-regular fa-calendar">` ×7 全部替换，删除 cdnjs 的 FA 6.5.1 全量 CSS link（约 100KB，阻塞渲染）
- portfolio.css 的 `.qualification__calendar` 只作用于容器 flex/透明度，不针对 `i`，替换安全
