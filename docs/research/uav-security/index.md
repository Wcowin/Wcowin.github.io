# 低空无人机安全

低空经济与无人机系统的快速部署，使安全议题从"工程可靠性"上升到"对抗环境下的系统性安全"。本栏目从**信息物理系统安全（cyber-physical security）与密码学应用**两条主线出发，研究无人机在通信、身份、集群与空域等层面面临的安全威胁及其防护机制。

> 定位说明：本站研究的脊柱是网络安全与密码学，低空方向作为其在物理世界的具体落点——因此本栏目的重心不在通用交通工程，而在**对抗条件下的安全**。

## 研究子方向

<div class="grid cards" markdown>

-   :material-antenna:{ .lg .middle } __通信安全与抗干扰__

    ---

    无人机链路（遥控、遥测、图传）的物理层与网络层防护：抗 jamming、抗劫持、安全信道与密钥协商。

-   :material-lock:{ .lg .middle } __身份鉴权与抗欺骗__

    ---

    GPS/INS 抗欺骗、设备与飞手身份认证、基于密码学的飞行指令完整性保护。

-   :material-account-group:{ .lg .middle } __集群安全与可信协同__

    ---

    多机协同中的安全共识、抗恶意节点、可信任务分配与拜占庭容错。

-   :material-clipboard-check:{ .lg .middle } __可验证遥测与取证__

    ---

    飞行数据的完整性校验、可验证日志、事后取证与责任追溯。

-   :material-radar:{ .lg .middle } __反无人机（counter-UAS）__

    ---

    非合作无人机的探测、识别与处置，含信号层与行为层防护。

-   :material-map:{ .lg .middle } __空域安全治理__

    ---

    空域准入、冲突检测与解脱（CD&R）在对抗条件下的鲁棒化，以及监管合规。

</div>
